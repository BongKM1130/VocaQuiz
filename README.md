# VocaQuiz
영단어 학습을 위한 Java GUI 퀴즈 프로그램

영어공부와 코딩을 동시에 잘하고 싶어서 만들었습니다.

data/words.txt 수정을 통해 영단어 추가 가능.

**주요기능**
- 랜덤 단어 문제 출제
- 5지선다 퀴즈
- 정답 / 오답 판별
- 점수 시스템
- 중복 문제 방지
- 모든 문제 출제시 자동초기화

  
 **사용기술**
- Java
- Java Swing
- Eclipse WindowBuilder

  
  **프로젝트 구조**

src
 ├─ model
 ├─ service
 └─ ui

data
 └─ words.txt

**실행 방법**

QuizFrame.java 실행
